DUNGEON ADVENTURE ONLINE — พร้อมนำขึ้นโฮสต์

โปรเจกต์นี้รวมหน้าเกม + WebSocket server ในบริการเดียว
- 2–4 คน
- สร้าง/เข้าห้องด้วย Room Code
- Host กดเริ่มเกม
- เกมจบอัตโนมัติหลังครบ 5 รอบ
- รองรับ HTTPS/WSS เมื่อโฮสต์ให้บริการ HTTPS

วิธีรันบนคอม:
npm install
npm start
เปิด http://localhost:3001

นำขึ้น Render:
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub เป็น repository
2. Render > New > Web Service > เชื่อม GitHub repository
3. Build Command: npm install
4. Start Command: npm start
5. เลือก Free เพื่อทดลอง
6. เปิด URL ที่ Render ให้มา

หมายเหตุ: Free Web Service ของ Render อาจหยุดทำงานเมื่อไม่มีการใช้งาน และอาจใช้เวลาประมาณหนึ่งนาทีในการตื่นกลับมา
